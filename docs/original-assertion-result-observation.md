## Existing computation only

`14a408335e17a090df1e26bdbeaf80d8122a8fd8`, the original CLI/compiler/archive
hashes, and the original Orchestra source hash. The full unchanged source of

unknown or altered source are unobserved.

A context is passed explicitly through the original sequential dispatch,
assertion, evaluateCondition and findElement path. There is no ThreadLocal,
listener replacement, cached hierarchy or wall-time association. A wrapper

already-returned List size, and returns that identical List or thrown object.
The original filter is not evaluated twice. No target getter, tree traversal,
geometry extraction, hierarchy/device/AX query or input is added.

This count is the output of Maestro's existing deepest/clickable reduction,
not the number of all raw matches or proof of uniqueness. An ambiguous input

invocation ID identifies the original filter computation, not an independently
attested HTTP/XCTest request. Query errors before filtering have no matcher
result and stay explicitly unavailable.

## Limits and retention

There are at most two contexts per process, 16 matcher passes and 40 records
per context, 1024 bytes per record and 16 KiB per context. The existing flow
source is hashed only below 262144 characters, at most 1 MiB of UTF-8 input.
Records contain only fixed source/run/attempt identity, numeric process/context/
authored-command/runtime-command/selector/polarity IDs, stages, outcomes,
nullable monotonic clocks, returned counts and finite error classes. Raw
selectors, labels, AX trees, URLs, errors, environment or user values are not
exported. A throwing/unsupported size read records unavailable, not a new error.

Primitive records are copied before possible later result mutation. They are
buffered until the original assertion finishes, then emitted on its existing
stderr channel. No writer thread, timer or sampler is added. Copying, hashing
and I/O perturb timing. Kernel/PrintStream blocking and delivery are unattested;
there is no zero-overhead claim or subtraction from historical timings.

The existing Node stderr capture is filtered into an exclusive private
`scenario-assertion-results.json` before the interaction returns and before
the evidence snapshot. Only the phone5 Solo scenario with independently bound
source/run/attempt/build proof receives enablement. Other identity and all
credential fields remain filtered. The parser enforces 32 KiB/80 records,
sequence/query pairing, identity, fixed keys, integer ranges and terminal
contexts. Missing, malformed, capped, unterminated or partial output remains
unavailable/partial; absence proves nothing. Existing evidence is never
overwritten, and optional retention errors cannot replace the original result.
