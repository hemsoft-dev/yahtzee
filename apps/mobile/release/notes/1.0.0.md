# Third Roll 1.0.0

Proposed first iOS release. No release date, uploaded build or public App Store
version exists in this record. Build 1 is a proposal until upload history is
checked. The [candidate record](../candidate.json) binds this note to the
changelog, native configuration, source, archive, screenshots and TestFlight
receipts. The release checker verifies this path matches the marketing version.

## Added

- Play house-rule dice games with five, six, eight or ten dice. Hold and reroll,
  then choose a score category. Play solo or against up to three computer
  opponents. [Implementation](https://github.com/hemsoft-dev/yahtzee/pull/57).
- Continue acknowledged games saved on the device. View local history and high
  scores per dice mode, with explicit save recovery and reset controls.
- Read built-in rules, choose System, Light or Dark appearance, and preview
  optional diagnostics before sharing.
- Find [support](https://hemsoft-dev.github.io/yahtzee/support.html) and the
  [privacy policy](https://hemsoft-dev.github.io/yahtzee/privacy.html).

These describe implemented source awaiting signed-device acceptance. They do
not claim a shipped build, global rankings, cloud sync or remote multiplayer.
