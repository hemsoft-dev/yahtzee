# Security and sensitive reports

This is a public repository. Do not post vulnerabilities, player names, saved documents, score history, credentials, device identifiers or private screenshots in a public issue or discussion.

## Private reporting is not available yet

An owner-approved private support and security contact has not been selected. GitHub private vulnerability reporting was disabled when checked on October 1, 2026 EDT. This document does not enable it or promise a working private channel. Do not use another project's contact address or send secrets to a guessed address.

Keep sensitive details private until the owner provides an authorized reporting route. [Issue #44](https://github.com/HemSoft/yahtzee/issues/44) tracks that missing route. This issue is public too, so do not put the sensitive report there. No response deadline or bounty is offered.

## Non-sensitive problems

Use the public [bug or feature issue page](https://github.com/HemSoft/yahtzee/issues/new/choose) for non-sensitive gameplay and usability reports. It requires a GitHub account. Use fictional examples and review any included text or image before posting.

The native diagnostics preview contains allowlisted app/OS/layout/schema details and sends nothing automatically. It is not a save export or a private reporting channel. The app's system share sheet sends only the previewed text when the user chooses a destination; that destination may use its own network service.

[The native development privacy draft](apps/mobile/PRIVACY.md) describes local data and sharing limits. It is not an approved policy for a published app.
